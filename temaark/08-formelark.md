# 8. Formelark 1T

Alle de viktigste reglene på ett sted. Fint å repetere fra før prøver!

## Algebra

| Regel | Formel |
|---|---|
| Potenser | $a^m a^n = a^{m+n}$, $\ \dfrac{a^m}{a^n} = a^{m-n}$, $\ (a^m)^n = a^{mn}$, $\ (ab)^n = a^n b^n$ |
| | $a^0 = 1$, $\ a^{-n} = \dfrac{1}{a^n}$, $\ a^{\frac{m}{n}} = \sqrt[n]{a^m}$ |
| Standardform | $a \cdot 10^k$, der $1 \le a < 10$ |
| Kvadratsetninger | $(a \pm b)^2 = a^2 \pm 2ab + b^2$, $\ (a+b)(a-b) = a^2 - b^2$ |
| Faktorisering | $ax^2 + bx + c = a(x - x_1)(x - x_2)$ |

## Likninger og ulikheter

| Regel | Formel |
|---|---|
| abc-formelen | $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ |
| Diskriminant | $D = b^2 - 4ac$: to, én eller ingen løsninger |
| Fullstendig kvadrat | $x^2 + bx = \left(x + \frac{b}{2}\right)^2 - \left(\frac{b}{2}\right)^2$ |
| Ulikheter | Snu tegnet når du ganger eller deler med et negativt tall |

## Funksjoner

| Regel | Formel |
|---|---|
| Lineær | $f(x) = ax + b$, $\ a = \dfrac{y_2 - y_1}{x_2 - x_1}$, $\ y - y_1 = a(x - x_1)$ |
| Andregrads | $f(x) = ax^2 + bx + c$, symmetrilinje $x = -\dfrac{b}{2a}$ |
| Toppunktform | $f(x) = a(x - p)^2 + q$ har topp- eller bunnpunkt i $(p, q)$ |
| Rasjonal | $f(x) = \dfrac{ax + b}{cx + d}$: vertikal asymptote der $cx + d = 0$, horisontal $y = \dfrac{a}{c}$ |
| Eksponential | $f(x) = a \cdot b^x$, vekstfaktor $b = 1 + \dfrac{p}{100}$ |
| Potens | $f(x) = a \cdot x^b$ |

## Polynomdivisjon

| Regel | Formel |
|---|---|
| Nullpunktsetningen | $P(a) = 0 \iff (x - a)$ er en faktor i $P(x)$ |
| Restsetningen | Resten ved $P(x) : (x - a)$ er $P(a)$ |

## Derivasjon

| Regel | Formel |
|---|---|
| Gjennomsnittlig vekstfart | $\dfrac{f(b) - f(a)}{b - a}$ |
| Definisjon | $f'(x) = \displaystyle\lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$ |
| Regler | $(c)' = 0$, $\ (x^n)' = nx^{n-1}$, $\ (c \cdot f)' = c \cdot f'$, $\ (f + g)' = f' + g'$ |
| Tangent | $y - f(a) = f'(a)(x - a)$ |
| Drøfting | $f' > 0$: stiger. $f' < 0$: synker. $f' = 0$: mulig topp- eller bunnpunkt |

## Trigonometri

| Regel | Formel |
|---|---|
| Rettvinklet | $\sin v = \dfrac{\text{mot}}{\text{hyp}}$, $\ \cos v = \dfrac{\text{hos}}{\text{hyp}}$, $\ \tan v = \dfrac{\text{mot}}{\text{hos}}$ |
| Pytagoras | $a^2 + b^2 = c^2$ |
| Stumpe vinkler | $\sin(180° - v) = \sin v$, $\ \cos(180° - v) = -\cos v$ |
| Arealsetningen | $A = \dfrac{1}{2}ab\sin C$ |
| Sinussetningen | $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$ |
| Cosinussetningen | $a^2 = b^2 + c^2 - 2bc\cos A$ |
